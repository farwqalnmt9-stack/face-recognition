# منصة كاجو الهندسية

أساس Django لمنصة كاجو: موقع رسمي ثنائي اللغة، إدارة منتجات، CRM، تراخيص، وكلاء، وسائط، وكلمات مفتاحية SEO.

## التشغيل

```powershell
.\.venv\Scripts\Activate.ps1
python manage.py runserver
```

ثم افتح `http://localhost:8000/`.

الصفحات العامة:

- `/` الصفحة الرئيسية.
- `/products/` مكتبة المنتجات بمسارين متعاكسين.
- `/products/<slug>/` صفحة تفاصيل كل منتج.
- `/login/` تسجيل الدخول المقسّم بصرياً.

## لوحة الإدارة

أنشئ حساب المدير محلياً باستخدام:

```powershell
python manage.py createsuperuser
```

ثم افتح `http://localhost:8000/admin/` لإدارة المنتجات والعملاء والتراخيص والوكلاء وفرص المبيعات والوسائط والكلمات المفتاحية.

## البنية الحالية

- `config/`: إعدادات المشروع والمسارات.
- `web/`: الموقع العام، نماذج النطاق، ولوحة Django Admin.
- `web/templates/web/`: واجهة الموقع.
- `web/static/web/`: الستايل والتفاعل والوسائط.

قبل النشر الإنتاجي: انقل `SECRET_KEY` إلى متغيرات البيئة، اضبط `ALLOWED_HOSTS`، وانتقل إلى PostgreSQL وCloudflare R2/S3 للوسائط.
